# Não aparecer no Google, mas APARECER no WhatsApp.
#
# São duas coisas diferentes e é fácil confundir — eu confundi, na versão
# anterior deste arquivo, que trazia `Disallow: /`:
#
#   · `Disallow` impede o robô de LER a página;
#   · `noindex` deixa ler e proíbe INDEXAR.
#
# Bloquear a leitura derruba junto o preview do link, porque o robô do
# WhatsApp precisa ler as tags og: para montar o cartão. E é pior que
# inútil para o buscador: sem poder ler, ele nunca vê o `noindex` — e pode
# listar o endereço mesmo assim, se alguém apontar um link para cá.
#
# Então: leitura liberada, e o `X-Robots-Tag: noindex, nofollow` do
# vercel.json é quem mantém a plataforma fora da busca.
#
# Isto não protege dado nenhum. A brecha de verdade — a tabela do Supabase
# aberta para quem tem o link — está em
# docs/ENGINEERING/SUPABASE_FECHAR_A_BRECHA.md e só fecha com login.
User-agent: *
Allow: /
